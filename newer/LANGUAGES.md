# Language build rule

English, Russian, and Hebrew are one release unit.

Every new page, component, navigation change, animation label, metadata update, and accessibility change must be created and checked in all three languages before the release is considered complete. Russian and Hebrew are not later translation passes.

Shared visual code and media remain common. Language-specific text, metadata, direction, and accessibility labels live in the English root, `/ru/`, and `/he/` versions respectively.
